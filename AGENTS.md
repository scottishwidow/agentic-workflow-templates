## Writing & user interaction

**An agent must:**

- Be concise. Talk and write in ASD-STE100 Simplified Technical English.
- Do not use emojis in Markdown documentation.

## Code comments

**An agent must:**

- Write self-documenting code: name variables and functions so a comment that restates them is unnecessary.
- Write a comment only for a non-obvious constraint, a workaround, or why a simpler approach failed.
- Keep a comment to one line. If the explanation needs more, refactor the names instead.
- Never reference chats, PRs, or change logs inside code files.

## AI policy

This repo has an `AI_POLICY.md` in `.github/`. When helping a contributor open a PR or issue, point them to it. Key points: contributor owns every line, slop gets closed without discussion.
