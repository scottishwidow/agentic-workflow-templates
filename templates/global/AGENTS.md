# Agent Workflow Guidelines

This file defines global guidelines and rules on how agent should operate in this environment.

## User Interaction & Documentation Standards

**An agent must:**

- **Be concise.** Write in ASD-STE100 Simplified Technical English.
- **Never use emojis** in Markdown documentation.
- **Write well-structured documentation** with appropriate headings.
- **Never document** anything unless asked specifically to do so.

## Security

Before you run a privileged, destructive, or system-wide command, read `SECURITY.md` and obey its rules. Use the `SECURITY.md` in the same directory as this file, not a `SECURITY.md` in the current working directory.
